## 实现与可核对入口

| 内容 | 代码与行为 |
| --- | --- |
| 执行器 | `server/src/assistant/execution.ts`：服务端生成 requestId、记录接受的 callId；查询/说明分开计状态，单轮查询锁存，查询成功后才发 houses。SSE 背压不造成“查询计数增加但仓库未调用”。 |
| 执行前纠错 | `service.ts` / `chatModel.ts`：仅漏调用、JSON、参数类型错误最多纠正一次；没有网络/查询/说明自动重试。未知工具、SQL/权限等额外字段直接拒绝。取消、过期或身份检查失败即停止后续操作。 |
| 条件核对 | `constraints.ts`：城市来自用户证据；核对高置信月租上下限及房型，支持明确跨轮修改/清除。城市多选、模糊金额、上下限冲突、年租/排除房型等需澄清，不自动放宽，不做通用语义纠错。多个检索提议且无法确定唯一城市时整体拒绝执行，再澄清。 |
| SSE | `protocol.ts`、前端 `assistantProtocol.ts`：每个事件关联请求/调用；检索须依次收到 running、succeeded、对应 houses 才可完成，空数组合法；问答/澄清走 not_required。正文只是 delta，不能创建卡片、改执行状态。 |
| 页面与上下文 | `AiAssistant.vue`：查询成功、说明失败/取消时保留卡片和已确认条件；用户可明确发起新一轮。已执行的用户条件可以进入历史，半截说明/未执行条件排除。未收到结果却完成时显示失败及“结果未确认”。刷新不缓存旧库存。 |
| Markdown | `markdown.ts`：保留 HTML 禁用与 DOMPurify 白名单；模型链接全部显示成纯文本，图片不能加载；真实卡片详情/列表/地图按钮独立创建。 |
| 日志 | 仅 requestId/callId、状态、耗时、返回/匹配条数、模型/纠错/查询次数及错误码；纠错阶段保留触发码。不记录完整对话、用户 ID、参数、房源内容或上游原文。 |

## 剩余限制与简历口径

条件校验是有限高置信表达的证据核对；复杂否定、多义地名、跨句语义或不支持的条件可能需要澄清，不保证所有表达都能被理解。模型正文仍可能出现错误/不当常识，状态机与净化保证的是执行和呈现边界，不能保证文字永不幻觉。没有RAG、通用自主Agent、跨请求去重/outbox、持久化执行恢复、SSE断点续传、分布式限流或集中JWT撤销；客户端取消不保证SQL回滚或上游未计费。模型链接纯文本化包含正常外链，牺牲了便利性；可信导航由卡片承担。

可使用的一条简历表述：**基于 DeepSeek Function Calling 实现自然语言找房，设计服务端受控执行器、一次执行前纠错及城市/预算硬条件校验，结合 SSE 关联校验与安全 Markdown，处理查询成功但说明失败、取消和异常事件，保证单轮至多一次只读检索。**

“单轮至多一次”限定为当前请求执行器内，不得改成跨请求 exactly-once、零幻觉或生产级 Agent。
